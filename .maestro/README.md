# Maestro-Abläufe

Je ein Ende-zu-Ende-Ablauf für Ansehen, Melden und den Fahrmodus (Simulation). Die Texte sind die **englischen** (Gerätesprache Englisch einstellen). Start: `maestro test .maestro/` auf einem Gerät oder Emulator mit dem Development-Build.

**Stand: geschrieben, nicht ausgeführt.** Hier gibt es kein Gerät und keinen Emulator; die Abläufe sind also ungeprüft und können Anpassungen brauchen (Wartezeiten, Berechtigungsdialoge). Ansehen und Melden brauchen einen Server mit Daten und einen Zugang (`docs/todo.md`); die Simulationsfahrt nicht.
